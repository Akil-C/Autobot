# Autobot – Premium Automotive Showroom Platform

This repository contains a full‑stack web application for a premium automotive showroom.

- **Frontend**: React 18+, Vite, TypeScript, Tailwind CSS, Framer Motion, React Three Fiber
- **Backend**: Java 21, Spring Boot 3+, Spring Security, JWT, Flyway, MySQL
- **Infrastructure**: Docker, Docker‑Compose, Nginx, GitHub Actions CI/CD

The project is organized in two main folders:

```
Automotor/
├─ backend/   # Spring Boot API
└─ frontend/  # React UI
```

See the `README` files inside each sub‑folder for detailed setup instructions.
